# Symbiont — release documentation

This section is the public narrative front door on what a Symbiont is and what real experimentation shows. It does not replace the canonical technical documentation (`docs/architecture.md`, `docs/math/`, `docs/roadmap.md`): each chapter cites its exact source in [`FUENTES.md`](FUENTES.md) and links to the technical document instead of repeating its numbers.

- **Researcher** — [09](09-metodologia-y-limites.md) → relevant experimental chapters ([05](05-fisiologia.md), [06](06-reproduccion-y-linaje.md), [07](07-ecologia-y-sociabilidad.md), [08](08-desarrollo-predictivo.md)) → open gaps.
- **Implementer** — [02](02-cuerpo-y-percepcion.md) → [03](03-cognicion-y-plasticidad.md) / [04](04-atencion-y-decision.md): host boundary, tick cycle and kernel limits.
