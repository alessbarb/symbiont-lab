# Selection parts

## Purpose

The six selection parts of governed run `cee-v1-selection-parallel-20261003`,
each 36 of the 216 (arm, seed) runs, as the launcher committed them.

## Belongs here

Only those six part files.

## Does not belong here

The merged selection, which is `../selection.json`.

## Criterion for creating a file

None: this folder is closed.

## Execution

Merged by `competence_establishment select --parts ...` into `../selection.json`.

## Limits

Exploratory selection data; it supports no claim by itself.
