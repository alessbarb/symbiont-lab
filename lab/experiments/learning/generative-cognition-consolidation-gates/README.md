# Generative Cognition consolidation gates

## Purpose

This registered assay covers **GC-E11** and **GC-E12** at the structural
admission boundary. Repeated generated use plus two independent factual source
references may project a bounded candidate to structural contention. Removing
generated reuse or source diversity must suppress that projection; repeating a
single replay source across many generated episodes must not manufacture
consolidation.

The assay measures admission signals and provenance guards, not the external
truth or usefulness of a structural mutation.

## Hypothesis

Structural admission requires both repeated generated use and independent factual source diversity; repeated replay from a single source will not manufacture consolidation.

## Belongs here

This directory contains the registered protocol metadata and the instructions
for reproducing this bounded consolidation-gates assay.

## Does not belong here

Pytest files, reusable study implementation, generated run artifacts and
unreviewed external-world claims do not belong in this directory.

## Criterion for creating a file

Add a file only when it is required to define, reproduce or interpret this
registered protocol. Put reusable code under `src/` and tests under `tests/`.

## Execution

Run it with:

```bash
symbiont-lab study run learning.generative-cognition-consolidation-gates
```

## Limits

The contents are evidence bounded by the protocol and do not demonstrate
generalization by themselves.
