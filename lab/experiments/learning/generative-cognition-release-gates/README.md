# Generative Cognition release gates

## Purpose

This registered protocol defines the core release gates for Generative Cognition v1:
**GC-E5**, **GC-E10**, and **GC-E13**.

## Hypothesis

Generative Cognition can produce and reconcile non-factual hypotheses without
creating factual contamination; endogenous agenda control can stop resolved or
stagnant targets; and mature source-diverse generative consolidation cannot
override generic anti-rumination to monopolise cognition.

## Belongs here

Preregistered protocol configurations, manifests, and execution parameters for the Generative Cognition release gates.

## Does not belong here

Unit tests, production code, or transient run artifacts.

## Criterion for creating a file

Add only files required for this reproducible protocol definition or its registered gates; mechanical test contracts belong in `tests/experiments/`.

## Execution

Run it with:

```bash
symbiont-lab experiment run experiments/learning/generative-cognition-release-gates/experiment.toml
```

## Limits

Results are evidence bounded by this synthetic sequence, these seeds and budgets;
they do not by themselves demonstrate generalization or open-world autonomy.
