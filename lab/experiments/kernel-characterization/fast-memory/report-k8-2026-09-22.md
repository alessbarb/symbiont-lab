# K8 — Fast-memory gate

## Result

The 5 × 4 threshold/reliability grid was executed with ten paired seeds per
cell. Reliable salient events were committed for thresholds 0.60–0.90;
threshold 0.95 rejected the synthetic event whose score is 0.90. Low-score
events were rejected in every cell, so the screen observed zero false fast
commits.

This is a gate-boundary and false-positive smoke test, not a ROC estimate:
the synthetic events are deliberately separated and do not include borderline
or correlated noise. Keep the canonical `0.80 / 0.60` control and do not tune
production from this screen alone.
