# Anatomy of learning

A learning event should be described by the state that changed, the evidence that caused the change and the later behaviour that can be affected by it.

There is no single global “learn” call. Learning is distributed across several mechanisms.

## Perceptual learning

Sensory statistics change with repeated observations. Structural sensory plasticity can create new sensors or change their source organisation. The resulting phenotype affects which future signals can be represented and at what cost.

## Cognitive learning

Prediction errors, evidence revision and recurrent activation alter graph state and confidence. Structural candidates may mature into persistent cognitive structure or later be retired.

## Sensorimotor learning

An executed action creates a transition only after its consequence has been observed. Repeated transitions accumulate causal evidence. Candidate competences are promoted only when recurrence, controllability and consistency gates are satisfied.

## Executive learning

Outcome learning modifies later admission or suppression of actions based on real outcomes. This is distinct from simply learning a motor controller: one mechanism learns how to perform an action, another can learn whether admitting that action is useful under similar conditions.

## Generative learning

Generated hypotheses or replayed episodes can alter internal organisation only through the bounded reconciliation and consolidation mechanisms. Generated states are not allowed to masquerade as factual observations.

## Persistence test

For any claimed learning event ask:

1. What exact state changed?
2. What causal evidence produced the change?
3. Can the change be checkpointed and restored?
4. Does it survive re-embodiment?
5. Is it inherited by offspring, culturally transmitted, or neither?
6. Which later computation consumes the changed state?

If those questions cannot be answered, “learning” is still only a descriptive label.
