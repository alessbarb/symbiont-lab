# Environment

A self-contained library for the medium an organism interacts with: world
state, laws, dynamics and ground truth. The environment may hold truth; nothing
here decides what an organism receives.

Import package: `environment`. Standard library only. It knows no Symbiont, no
Embodiment, no Modality and no Lab. Enforced by
`tests/experimental_integrity/test_five_domain_architecture.py`; checked alone by
`environment/tests`.
