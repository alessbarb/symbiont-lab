# Observatory browser QA — 2026-09-18

## Scope

Interactive QA of the current Observatory after the population-telemetry
integration fix. This is UI/integration evidence, not scientific evidence for
any organism capability.

## Environment

- Browser: Google Chrome 152.0.7977.82, headless mode, Chrome DevTools
  Protocol over localhost.
- Server: `python3 observatory/server.py --port 8898 --observatory-dir /tmp/symbiont-observatory-empty`.
- Fixture: `/tmp/integrated-observatory-replay.json`, generated by the canonical
  `IntegratedHabitatRuntime` (seed 101, 8 ticks, real birth/death probe,
  communication telemetry and bounded history).
- Transport: same-origin `MessageEvent` snapshot ingestion; no external network
  or remote peer discovery.

## Interactions executed

1. Loaded the real server and verified title/layout and absence of current
   runtime exceptions.
2. Switched between Individual and Population views.
3. Injected the runtime-derived population snapshot and opened Population.
   The panel rendered 16 factual events, 4 observed directed edges, and one
   opaque sequence message; sender/receiver/tick/delivery/cost were visible.
4. Applied sender and message filters, then cleared them. Filtering reduced
   visible events without changing the aggregate history.
5. Opened the individual organism profile and inspected identity/state and the
   organism-facing panels; no evaluator meaning was displayed.
6. Verified the empty state on a fresh navigation: zero events, zero edges and
   zero messages, with explicit empty-state text.
7. Loaded a legacy snapshot with `population_telemetry` absent on a fresh run;
   it loaded without fatal errors and showed the same explicit empty fallback.
8. Injected a truncated telemetry snapshot and verified the visible warning
   `History truncated · earliest available tick 5`.
9. Tested the narrow 480px viewport and restored the desktop viewport. The
   layout remained usable; long opaque identifiers remained in scrollable
   tables and the off-canvas inspector stayed hidden rather than covering the
   communication canvas.
10. Captured `/tmp/observatory-browser-qa.png` for manual visual inspection.

## Browser console/network result

No current page exception was observed during the clean navigation and
interactions. The real server served the application without the static-server
`/fleet` 404. No external network requests were introduced. The known PyTorch
nested-tensor warning is unrelated to this browser run.

## Verdict

`browser_qa = PASS` for the exercised scope. The test is bounded to the
available fixture/history and does not claim exhaustive production-scale UI
coverage. Observatory remains passive/read-only; all lineage and graph edges
shown by the population panel come from exported events.
